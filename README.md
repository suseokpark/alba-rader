# 알바레이더

알바몬 → 당근 → 알바천국 순서로 실제 공개 공고를 함께 조회하는 SvelteKit 프로토타입입니다.

## 실행

Node.js 22.12 이상(22.x) 또는 24 이상을 사용하세요.

```sh
npm ci
npm run db:migrate:local
npm run dev -- --host 127.0.0.1 --port 5173
```

같은 컴퓨터의 Chrome에서 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)을 엽니다. 주소 찾기에서 기준 주소를 지정한 뒤 지역 단위와 검색어를 선택합니다. 기본값은 **주소 기준 · 시·군·구**이며 알바몬·알바천국을 조회합니다. **동·읍·면**으로 바꾸면 당근도 함께 검색할 수 있습니다. **당근 여러 동네 선택**을 켜면 기준 주소의 범위와 별개로 최대 5개 동네를 추가할 수 있습니다. 전국을 선택하면 알바몬·알바천국은 전국, 여러 동네 모드의 당근은 별도로 선택한 동네만 조회합니다.

## 기능

- 다음·카카오 우편번호 검색으로 주소 선택 및 변경
- 기준 주소, 당근 선택 동네와 조회 결과의 동네를 카카오맵 새 탭에서 보기
- 선택한 지원 업체 병렬 조회, 업체별 로딩·조회 실패·검색 결과 0건 구분
- 지역 단위 선택: 동·읍·면, 시·군·구, 시·도 전체. 구가 있는 일반시에는 시·군 전체도 표시
- 주소 범위 확장: 서울 마포구 → 서울 전체, 경기 수원시 영통구 → 수원시 전체 → 경기 전체
- 당근 기본 모드는 동·읍·면에서 활성화. 여러 동네 모드에서는 구·시·도·전국 설정과 별개로 선택한 동네들을 검색
- 당근 최대 5개 고유 동·읍·면 선택, 동네별 조회 상태·원문 링크와 중복 제거 수 표시
- 급여 형태, 최소 시급, 명시된 근무요일, 근무 시작 시간대, 제목·회사명 포함/제외 키워드 필터
- 요일·시간 미확인 공고 포함 옵션과 확인 필요 배지, 필터 초기화
- 업체 기본순·시급 높은순 정렬, 실제 공고 원문 링크
- 공고 클릭 서버 집계 및 `/analytics`에서 최근 7일·30일 / 업체별 클릭 순위 확인

## 클릭 통계

화면 위의 **클릭 통계**에서 검색 결과의 공고별 클릭 횟수, 클릭된 공고 수, 업체별 합계와 상위 30개 공고를 확인합니다. 오늘을 포함한 한국 시간 달력일 기준이며, 도입 전의 클릭은 소급하지 않습니다. 클릭 수에는 같은 사람이 반복해서 연 횟수가 포함됩니다. 사람 수·CTR·지원 수·원문 도착 성공을 의미하지 않습니다.

공고 클릭 때만 같은 앱의 `/api/clicks`로 전송하고 D1에 저장합니다. 데이터는 업체·canonical 공고 URL/키·공개 제목/사업장명·서버 수신 시각·클릭별 일회성 UUID입니다. 사용자 검색어·지정 주소·이름·IP·UA·쿠키/방문자 ID는 집계 DB에 저장하지 않으며, 호스팅 제공자의 접근 로그는 별개입니다. 원문 공고 메타데이터 자체에는 공개된 지명이 포함될 수 있습니다. UUID 재전송은 DB 보존 범위에서 중복 제거합니다. 90일 지난 이벤트는 이후 클릭 때 최대 100개씩 순차 삭제합니다. 분석 화면은 최근 30일까지만 제공합니다.

통계 링크의 재클릭, 지도, 업체 전체 검색 링크는 제외합니다. 연결 실패·추적 차단·우클릭 메뉴 열기는 누락될 수 있고, 자동화와 사람을 구분하지 않습니다. 클라이언트 이벤트를 받는 방식이므로 부정 클릭 방지·발급 공고 서명 검증을 구현한 것은 아닙니다. 통계 장애가 검색·원문 링크 열기를 막지 않습니다.

로컬 SQLite와 배포 D1은 **분리**되어 있으며 검증 클릭/합성 단위 데이터는 운영에 전송하지 않습니다. 로컬 DB는 Git 제외된 `.wrangler/state/`에 유지됩니다. `db/schema.ts` 변경 후 `npm run db:generate`, `npm run db:migrate:local`을 실행합니다. Drizzle SQL/메타만 배포하며 런타임 스키마 변경이나 테스트 데이터 삽입은 하지 않습니다. `wrangler.sites.jsonc`의 DB ID는 로컬용 placeholder이며 실제 배포 리소스는 Sites가 `.openai/hosting.json`의 논리 바인딩 `DB`로 연결합니다.

현재 통계의 외부 접근 보호는 **소유자 전용 Sites 게이트**에 의존합니다. 앱에 별도 관리자 인증은 없습니다. 향후 사이트를 공개하거나 공유 대상을 늘리기 전에 `/analytics`와 `/api/clicks` 조회 권한 정책을 별도로 결정해야 합니다. localhost는 외부 공개용 운영 서버가 아닙니다.

## 데이터와 한계

지역 단위는 공식 검색 조건으로 요청합니다. 알바몬은 선택한 지역 코드 집합 전체와 인근 지역 확장 해제를 확인합니다. 알바천국은 동·읍·면 선택 시에도 더 넓은 시·군·구 범위이며, 시 전체 검색에는 해당 시의 모든 구를 포함합니다. 알바천국의 선택 제한인 5개 구를 넘는 시는 일부 구만 조회하지 않고 지원 불가를 알립니다. 세종처럼 별도 시·군·구가 없는 주소는 해당 단위를 시·도 전체로 자동 변경합니다. 단위를 바꾼 뒤 검색 버튼을 눌러 적용하세요.

당근 여러 동네 선택은 기본적으로 꺼져 있습니다. 처음 켤 때 기준 주소가 있으면 해당 동네를 초기 목록에 넣습니다. 추가 주소 검색은 기준 주소를 바꾸지 않고 행정구역 정보만 목록에 보관합니다. 목록은 기준 주소 변경과 독립적이며, 기능을 꺼도 유지되지만 새로고침하면 사라집니다. 동네당 최대 20건을 최대 2곳씩 동시에 조회하고 중복 공고를 제거한 뒤 필터·정렬을 적용합니다. 일부 동네 조회가 실패하면 성공한 동네의 결과만 표시하며, 그 결과가 0건이어도 모든 선택 동네에 공고가 없다고 확정하지 않습니다. 각 동네 검색에는 주변 지역 공고가 포함될 수 있으며 당근의 구·시·도 전체 또는 전국 검색을 의미하지 않습니다.

지도 보기는 [카카오맵 공식 검색 링크](https://apis.map.kakao.com/web/guide/#mapurl)를 새 탭으로 엽니다. 클릭할 때만 기준 주소 전체 또는 당근의 시도·시군구·동읍면 이름을 카카오맵에 전달합니다. 기준 주소를 변경·삭제하면 해당 지도 링크도 갱신·숨김 처리하며, 조회 결과의 동네 지도는 조회 당시 동네를 유지합니다. 지도 API 키나 좌표 변환 없이 제공하는 주소·동네 검색으로, 공고 근무지의 정확한 위치나 검색 반경·경계를 표시하지 않습니다.

공개 검색의 첫 페이지 일부 공고만 불러옵니다. 필터와 정렬은 **불러온 공고 안에서만** 적용하며 업체 전체 결과를 대상으로 하지 않습니다. 알바천국의 현재 검색 목록에는 요일·시간 정보가 없어 해당 정보는 미확인으로 처리합니다. 급여 단위를 환산하거나 제목에서 근무조건을 추정하지 않습니다.

로그인·개인 계정·비공개 인증정보·테스트 공고를 사용하지 않습니다. 업체의 공개 페이지 구조나 응답 상태가 바뀌면 조회가 실패할 수 있습니다. 모집 상태와 지원 조건은 원문에서 확인해야 합니다. 정식 제휴 API 연동은 포함하지 않습니다.

## 배포

배포용 빌드는 SvelteKit의 Cloudflare 어댑터로 검색 API Worker와 정적 자산을 만듭니다. `npm run build`는 번들 생성과 `wrangler --dry-run`까지만 실행하며 원격 배포하지 않습니다. 로컬 `npm run dev`도 같은 어댑터의 로컬 D1 프록시를 사용하므로 최초 실행 전 로컬 마이그레이션이 필요합니다.

- 서버 번들: `dist/server/index.js`, 브라우저 자산: `dist/client/` (Git 제외)
- Sites 식별자: `.openai/hosting.json`. 새 사이트의 접근 범위는 소유자 전용이며 공유 범위를 임의로 확대하지 않습니다.
- 호스팅 설정: `wrangler.sites.jsonc`. 실제 게시에는 별도의 Sites 저장·배포 단계가 필요합니다.
- GitHub 원격 저장소와 배포 소스는 같은 커밋으로 맞춥니다. 반복 개선 자동화는 별도 요청 없이 push/배포하지 않습니다.
- 배포 성공과 외부 업체 실검색 성공은 별개입니다. 배포 서버에서 업체 응답이 제한될 수 있으며 조회 실패를 빈 공고로 표시하지 않습니다.

공식 주소 검색은 Chrome 새 탭에서 주소 선택 및 공고 조회까지 검증했습니다. 일부 내장 브라우저의 새 탭에서는 외부 주소 검색 프레임 차단이 재현되었으며, 이 제한은 해결되지 않았습니다.

## 검증

2026-09-25 Cycle24 기준 단위·정적 검사 294개, 타입 검사 오류·경고0, 빌드 통과. 아래 수치는 각 기능 도입 당시의 역사적 결과입니다. 최신 검증 범위는 [개선 루프 기록](docs/single-search-loop.md)을 참고하세요. 로컬 증거 이미지와 외부 실검색 결과를 Git에 포함하지 않습니다.

```sh
npm run check
npm run test:unit
npm run build
```

개발 서버가 실행 중일 때 실제 공개 공고 조회도 검사할 수 있습니다.

```sh
npm run test:search
npm run test:multi
```

대상 서버는 `ALBA_RADAR_BASE_URL` 환경변수로 바꿀 수 있습니다. 실조회 검사는 외부 서비스 상태에 따라 실패할 수 있으며, 단위 테스트의 통과가 외부 연결을 보장하지 않습니다.

지역 범위 확장 후 타입 검사 오류·경고 0건, 단위 테스트 57개, 빌드 및 실조회 검사를 통과했습니다. 실조회에는 동네 세 업체, 마포구·서울 전체, 영통구·수원시 전체·경기 전체와 지원하지 않는 범위의 차단 검사가 포함됩니다. 실제 Chrome에서도 주소 선택 후 구·시·도·동네·전국 전환과 필터 유지, 주소 변경 시 단위 정규화를 확인했습니다. 서울 전체 조회 중 한 차례 두 업체가 실패했고, 동일 조건 재검색에서는 30건이 정상 표시됐습니다. 외부 조회가 항상 성공한다고 보장하지 않습니다.

상세 구현 범위와 검증 기록은 [SEARCH-IMPLEMENTATION.md](SEARCH-IMPLEMENTATION.md)를 참고하세요.

당근 여러 동네 추가 후에는 타입 검사 오류·경고 0건, 단위 테스트 **70개**, 빌드, 기존 실조회 검사와 여러 동네 실조회 검사를 통과했습니다. Chrome에서 동교동·서교동·이의동 추가 및 조회, 중복 제거, 삭제 후 재검색, 전국 검색과의 병행, 필터 유지, 빈 목록 안내를 확인했습니다. 최초 다중 동네 실조회 검사는 두 동네 조회 실패로 실패했지만 후속 동일 조건 조회는 성공했습니다. 외부 조회의 간헐적 실패 가능성은 남아 있습니다.

지도 보기 추가 후에는 타입 검사 오류·경고 0건, 단위 테스트 **78개**, 빌드를 통과했습니다. Chrome에서 경기도청 주소와 이의동 링크를 실제로 눌러 카카오맵 새 탭의 검색 결과를 확인했고, 주소 변경·삭제에 따른 링크 갱신과 기존 검색어·필터 유지도 확인했습니다.
